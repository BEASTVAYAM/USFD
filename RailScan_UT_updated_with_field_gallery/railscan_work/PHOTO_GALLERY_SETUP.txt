   - rail-inspection-trolley.jpeg

How to use:
1. Extract this ZIP.
2. Open the extracted project folder in VS Code.
3. In the terminal, run: npm install
4. Then run: npm run dev
5. Open the local URL shown by Vite.
6. Click "Field Gallery" in the top navigation to view the photos.

To merge into an existing copy instead of replacing the whole project:
- Replace src/components/Dashboard.tsx with the one in this ZIP.
- Add src/components/FieldGallery.tsx.
- Copy the three files from public/images/ into your existing public/images/ folder.

No package dependencies were added.
